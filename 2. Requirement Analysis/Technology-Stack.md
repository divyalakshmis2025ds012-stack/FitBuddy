# Technology Stack

| Layer | Technology |
|---|---|
| Language | Python |
| Backend framework | FastAPI (served with Uvicorn) |
| Templates / UI | Jinja2, HTML/CSS |
| Database | SQLite through SQLAlchemy (`fitbuddy.db`, created on first run) |
| AI | Google Generative AI - Gemini 1.5 Pro (workout plan, revision), Gemini 1.5 Flash (nutrition tip) |
| Config | python-dotenv (`GOOGLE_API_KEY` in `.env`) |

Flow diagrams are in the `Diagrams` folder of this phase.
