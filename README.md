# FitBuddy - AI Fitness Plan Generator

Naan Mudhalvan project. FastAPI + Google Gemini + SQLite app that generates a personalised 7-day workout plan and a nutrition tip, revises the plan from user feedback, and has an admin page listing all users and plans.
